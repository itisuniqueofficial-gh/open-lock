Security issues

Found a vulnerability?

Please report it privately via the GitHub Security tab — not in a public issue — so it can be fixed responsibly.

Common problems

Quick fixes for lock timing.

  • Lock screen slow to appear: aggressive OEM battery limits can delay the guard — grant a battery-optimization exemption.
  • Lock not appearing at all: grant Usage Access and "display over other apps", and keep the foreground service running.
